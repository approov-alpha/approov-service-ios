# Security Policy

## Supported Versions

We supply updates and patches in the latest release. Version 3.7.0 is the first release of this package. For apps that use it, it replaces `approov-service-urlsession` and `approov-service-alamofire`. Those packages keep their own policies.

We recommend that you update to the latest version of this package.

| Version | Supported          |
| ------- | ------------------ |
| 3.7.x   | :white_check_mark: |

## Reporting a Vulnerability

Thank you for telling us about possible security vulnerabilities in this project.
Do not publish details in a public issue or pull request. Send a private email to support@approov.io. Tell us which version your report is about.

We reply to your message promptly.
